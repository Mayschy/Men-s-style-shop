# 📊 Управление количеством товара (Stock Management)

## Описание функционала

Система теперь полностью синхронизирует количество товара (stock) на всех уровнях:

### 🛒 Магазин (Shop)
- **Информация о количестве**: каждый товар показывает количество в наличии `✓ In Stock (5)`
- **Товары в наличии**: нормально отображаются и доступны для просмотра
- **Товары закончились** (stock = 0):
  - Карточка становится полупрозрачной (opacity 60%)
  - На изображении появляется большой баннер **"❌ OUT OF STOCK"**
  - Ссылка на товар неактивна - нельзя открыть страницу товара
  - Показывает **"✗ Out of Stock"** красным цветом

### 🔧 Админ панель (Admin Dashboard)
- **Добавление товара**: поле "Stock Quantity" обязательное при создании
- **Редактирование товара**: нажмите кнопку ✏️ Edit рядом с товаром
  - Открывается модальное окно с текущими данными
  - Измените количество в поле "Stock Quantity"
  - Сохраните изменения кнопкой "💾 Update Product"
- **Таблица товаров**: показывает текущее количество каждого товара
  - Зелёный фон: товар в наличии
  - Красный фон: товар закончился

### 🔄 Синхронизация

- Когда вы устанавливаете stock = 0 при редактировании/создании товара:
  - Флаг `isAvailable` автоматически устанавливается на `false`
  - Товар исчезает из доступных к покупке в магазине
  - Остаётся видимым для просмотра при поиске

- Когда вы восстанавливаете stock > 0:
  - Флаг `isAvailable` автоматически устанавливается на `true`
  - Товар снова становится доступным в магазине

## Поиск

### Админ панель
- 🔍 Поиск находит товары по названию и категории
- Помогает быстро найти товар для редактирования количества

### Магазин
- 🔍 Поиск находит товары по названию и описанию
- Показывает количество найденных товаров
- Поиск работает одновременно с фильтром по категориям

## Пример использования

### Добавить новый товар с 10 единицами:
1. Нажмите ➕ Add New Product
2. Заполните все поля включая "Stock Quantity: 10"
3. Нажмите ➕ Add Product
4. Товар появится в магазине со статусом "✓ In Stock (10)"

### Товар закончился - отметить как недоступный:
1. Найдите товар в админ панели через 🔍 поиск
2. Нажмите ✏️ Edit
3. Измените "Stock Quantity" на "0"
4. Нажмите 💾 Update Product
5. В магазине товар теперь будет недоступен с баннером "❌ OUT OF STOCK"

### Пополнить запас товара:
1. Найдите товар в админ панели
2. Нажмите ✏️ Edit
3. Измените количество на новое (например, с 0 на 15)
4. Нажмите 💾 Update Product
5. Товар снова доступен в магазине

---

**Важно**: Все изменения stock отправляются на сервер и сохраняются в БД! ✅
